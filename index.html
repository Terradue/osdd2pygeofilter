OpenSearch to pygeofilter¶

Generate a Python evaluator from an OpenSearch Description Document (OSDD) with osdd2pygeofilter. The generated module translates supported CQL2 filters into decoded OpenSearch query parameter dictionaries for that service.

Generate an evaluator¶

After installing the CLI, supply a description and an output file:

osdd2pygeofilter https://api.eumetsat.int/data/search-products/1.0.0/os --output eumetsat_evaluator.py

Local XML files work too:

osdd2pygeofilter ./opensearch.xml --output search_evaluator.py

The command creates parent directories and replaces an existing output file. It generates Python source; your application uses that module to convert filters and makes any search requests.
